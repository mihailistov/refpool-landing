# refpool.xyz — Crypto‑Native Influencer Marketplace (Landing Page)

A starter landing page built with **Next.js + Tailwind CSS**.

## Quickstart

```bash
# 1) Install deps
npm install

# 2) Run dev server
npm run dev

# 3) Build & start
npm run build && npm start
```

Open http://localhost:3000

## Customize

- Replace `/public/logo.svg`
- Update copy in `components/*` and meta tags in `pages/_app.tsx`
- Waitlist form posts to `/api/subscribe` — wire it to your DB/CRM

## Deploy

- Vercel: import the repo and deploy
- Netlify/Render: standard Next.js deployment

## Notes

- Analytics snippet (Plausible) is commented in `_app.tsx`
- Pricing and FAQ are placeholders — adjust to your model
- Add a custom domain and SSL where you deploy
